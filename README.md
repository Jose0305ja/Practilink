# Practilink

Plataforma web que conecta a los alumnos de la UTD con empresas de Durango que buscan practicantes o estadías.

## Problema
A los alumnos les cuesta encontrar empresa para sus prácticas: buscan a ciegas, sin saber qué empresas aceptan practicantes ni qué perfil piden.

## Objetivo
Reducir el tiempo que tarda un alumno en encontrar empresa y centralizar todas las vacantes de prácticas en un solo lugar.

## Funcionalidades
- Registro y perfiles de alumnos y empresas
- Publicación de vacantes y postulación
- Recomendaciones (match) según habilidades
- Reseñas de exalumnos
- Panel de Vinculación para la UTD

## Estructura
- `documentacion/descripcion.txt`: nombre, problema, objetivo y descripción del proyecto
- `src/index.html`: página inicial
